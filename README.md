# G75 高速边坡三维查看

基于大疆司空 2 导出的 OBJ 实景重建数据制作的网页演示。支持原始实景贴图与三维线面视图切换；实景视图提供三档模型细节。

在线演示：https://g75-slope-3d-viewer.z-zzzzq.chatgpt.site/

## 构建

需要 Python 3。运行 `python build.py`，然后打开生成的 `dist/index.html`。构建程序会把 `assets/` 中的网格、等高线与贴图嵌入单文件 HTML。网页使用 WebGL；没有可用 WebGL 的浏览器无法显示三维模型。

## 数据说明

- `lod0.bin`：63,475 个三角面，原始精细网格。
- `lod1.bin`：54,542 个三角面，0.75 m 网格聚类。
- `lod2.bin`：13,535 个三角面，2.4 m 网格聚类。
- `contour*.bin`：与对应 LOD 几何一致的 5 m 间隔相对高程线。
- `texture.jpg`：从 8192 × 8192 原贴图缩放到 2048 × 2048 的演示纹理。

每个 LOD 文件是连续的 little-endian float32 顶点数组，每个顶点依次为 `x, y, z, u, v`，每三个顶点构成一个三角形。等高线文件是连续的 float32 `x, y, z` 数组，每两个顶点构成一条线段。坐标在本地模型中心平移并转换为 WebGL 的 Y 向上视图坐标；源文件元数据为 EPSG:4491，原点 `(17107579.788325451, 2860647.1502400842, 129.31399999994034)`。

此仓库与在线 Sites 发布源是两个独立仓库。修改这里的代码不会自动更新在线网址；需要重新构建并发布到 Sites。
